# 白目の影をシェーダーで描く 設計

日付: 2026-10-11
前提: `2026-10-09-mtoon-maid-eye-gloss-design.md`（瞳の光沢）と、その後の瞳のハイライトの可変リスト（`2026-10-10-mtoon-maid-eye-highlight-list` の計画）までを引き継ぐ。ここに書いたことだけを変える。

## 背景

白目の上側の影の形と色を、瞳の「上まぶたの影」と同じようにスライダーで調整したい（ユーザーの要望）。ライトの向きに反応させることは目的にしない。

2026-10-11 に実機（顔 `face_tokinagare_sharp_z04`、COM3D2.5）で確かめた事実:

- 白目は head スロットの顔のレンダラー（`Face7`）の `Face006_Mouth` マテリアルが描いている。このマテリアルは口内・歯・舌・白目を 1 枚にまとめたアトラス（`58_mouth_prpr_p`、256×512）を使い、Toony から MToon10 へ変換済み（顔グループ）
- 白目はアトラスの左下 1/4 にあり、上側がベージュがかった灰色、下側が白いアーチに**描き込まれている**。これが今の白目の影の正体。顔の MToon の影色（`_ShadeColor`）・主光源の影マップ・主光源の向きを変えても、灰色と白の境界は変わらなかった
- 左右の目の白目の三角形は、同じ UV の範囲（u 0.021〜0.469、v 0.012〜0.499）を鏡像で共有している。UV の v は頭の上向きに増える（白目の上端が v の大きい側）
- 瞳（`EyeL` / `EyeR`）・`SkinAlpha`・`SkinHi` を消しても白目の影は残る。顔の肌（`Skin`）は白目の部分が穴になっている
- バニラの顔モデル（face003〜008）は、どれも `FaceXXX_Mouth` という名前のマテリアルを持つ（テクスチャも `FaceXXX_Mouth.png`）
- マテリアルは顔を読むたびに作られるため、メイドごとに別のインスタンスになる（名前に `(Instance)` が付かないのは、まだ `Renderer.materials` を通っていないだけ）

## 方式

MToon10 シェーダーに「白目の範囲だけ色を塗り替えて影を重ねる」処理を足す。白目の範囲（UV の外接矩形）は C# がメッシュから求めて `_ScleraRect` で渡す。矩形が未設定のマテリアルでは何もしない。

比べた案:

- MToon10 に足す（採用）: 口内・歯・舌は今の MToon の陰影・リム・アウトラインのまま残る。白目もそのあと通常のライティングを通るので、明るさは顔と同じくライトへ追従する
- 口のマテリアルを専用シェーダーへ差し替える: 白目の処理は分けて書けるが、口内の MToon の表現を作り直すことになり重複が大きい
- 白目だけを描く重ね描き: メッシュの複製と描画順の管理が要り、得るものがない

## シェーダー（`COM3D2/MToon10`）

### プロパティ

| 名前 | 型 | 既定 | 内容 |
|---|---|---|---|
| `_ScleraRect` | Vector | (0, 0, 0, 0) | 白目の UV の外接矩形（xy = 最小、zw = 大きさ）。zw が 0 なら白目の処理をしない |
| `_ScleraColor` | Color | (1, 1, 1, 0) | 白目の色。アルファが 0 ならテクスチャから取る（下記） |
| `_ScleraShadow` | Range(0, 1) | 0 | 影の濃さ（シェーダーの既定は 0。値はプラグインが入れる） |
| `_ScleraShadowColor` | Color | `#E0D3C9` | 影の色。白目の色に乗算する |
| `_ScleraShadowHeight` | Range(0, 1) | 0.5 | 白目の上端から測った、影のかかる範囲（白目の高さに対する割合） |
| `_ScleraShadowSoftness` | Range(0, 1) | 0.15 | 影の下の縁をぼかす幅（影の高さに対する割合） |
| `_ScleraShadowBend` | Range(0, 1) | 0.2 | 反り。白目の左右の端ほど影の縁を下げる量（白目の高さに対する割合） |
| `_ScleraLidFollow` | Range(0, 1) | 0.2 | まばたきの閉じた割合にこの値を掛けた分だけ、影を下へずらす |
| `_LidClose` | Range(0, 1) | 0 | まぶたを閉じた割合（瞳のシェーダーと同名。プラグインが毎フレーム入れる） |

### 描き方

- 白目の座標 `n` = (uv − `_ScleraRect.xy`) / `_ScleraRect.zw`。0〜1 の内側を白目とみなす。矩形の外は今と同じ
- 白目の色:
  - `_ScleraColor.a > 0` なら `_ScleraColor.rgb`
  - それ以外は、白目の矩形の横の中央・下から 1 割の位置のテクスチャの色（`_MainTex` を LOD 0 で読む）。そこはアトラスで白く塗られている部分で、テクスチャの色合いをそのまま引き継げる
  - 光側では `_Color` を掛け、影側では掛けない（元の `_ShadowTex` の経路も `_Color` を掛けないため）
- 影の縁の高さ: `edge = 1 − _ScleraShadowHeight − _ScleraShadowBend × (2n.x − 1)² − _LidClose × _ScleraLidFollow`。`n.y` が `edge` より上を影にし、`edge` から `_ScleraShadowSoftness × _ScleraShadowHeight` の幅でなめらかにつなぐ（瞳の上まぶたの影と同じ smoothstep）
- 塗り替えた色 = lerp(白目の色, 白目の色 × `_ScleraShadowColor`, 影 × `_ScleraShadow`)
- 光側の色（`_MainTex` から求める `litColor` / `baseColor`）と、影側で読む `_ShadowTex` の色の**両方**を、白目の内側だけ塗り替えた色へ置き換える。`_ShadowTex` は変換時に `_MainTex` を複製して入れているため、片方だけだと影側に描き込みの影が残る
- アルファは今のまま（`_MainTex` のアルファ）。アウトラインのパス・影を落とすパスは変えない

### 互換

- 既存のマテリアルは `_ScleraRect` が (0,0,0,0) なので見た目は変わらない
- Unity 5.6（COM3D2 2.0 のバンドル）でもコンパイルできる書き方にする（既存の `vrmc_materials_mtoon_compat.hlsl` の作法に従う）

## C# の構成

### 白目のマテリアルと範囲の見つけ方

- 対象は head スロットのマテリアルのうち、**名前に `Mouth` を含み**（大文字小文字を区別しない）、今のシェーダーが MToon10 のもの。顔グループが MToon になっていなければ何もしない
- 範囲は、そのマテリアルのサブメッシュの三角形のうち、3 頂点がすべて左右どちらかの瞳のサブメッシュ（番号 0 と 1）の頂点の外接箱（バインドポーズのメッシュ座標、目ごとに 1 個）の内側にあるものの UV の外接矩形とする。両目を 1 個の箱にすると目の間（鼻筋）の三角形まで入りうるため、目ごとに分ける。実機の顔では片目あたり 40 三角形が選ばれ、上記の UV の範囲になった
- 当てはまる三角形が無いときは範囲なしとし、`_ScleraRect` を (0,0,0,0) にする
- 求めた矩形はメッシュ（`sharedMesh` のインスタンス ID）と白目のマテリアルの番号ごとに覚え、どちらかが変わったときだけ求め直す
- 矩形を求める計算は、頂点・UV・三角形の配列を受け取る純粋な関数（`Rendering/ScleraBounds`）にし、Unity の型を使わずにテストする（`IrisBounds` と同じ作法）

### 値の入れ方

- 新しいクラス `MaidScleraShadow`（`MaidEyeGloss` と同じ単位で、メイド 1 人分）が、白目のマテリアルを見つけて `_ScleraRect` と設定値を入れる
  - 走査（`Scan`）で対象のマテリアルと矩形を決め、設定の変更（`Apply`）で値を入れ直す
  - 毎フレームの `_LidClose` は、瞳と同じ閉じた割合（`EyelidClosure.Sum`）を入れる。計算は `MaidEyeGloss` と共通にする
  - 無効にしたとき・マテリアルが外れたときは `_ScleraRect` を (0,0,0,0) に戻す。マテリアルのシェーダーや他のプロパティには触らない（MToon の変換・復元は今のまま `MaidMToonController` が行う）
- MToon から Toony へ戻したマテリアルに残る `_Sclera*` は Toony では使われないので消さなくてよい

### 設定（`EyeSettings` に足す）

| 項目 | 既定 | 範囲 |
|---|---|---|
| `scleraShadowEnabled` | false | 白目の影を描く。OFF なら今の見た目（テクスチャの描き込み）のまま |
| `scleraColorOverride` | false | 白目の色を指定する |
| `scleraColor` | 白 | 白目の色 |
| `scleraShadow` | 1 | 0〜1 |
| `scleraShadowColor` | `#E0D3C9` | 色 |
| `scleraShadowHeight` | 0.5 | 0〜1 |
| `scleraShadowSoftness` | 0.15 | 0〜1 |
| `scleraShadowBend` | 0.2 | 0〜1 |
| `scleraLidFollow` | 0.2 | 0〜1 |

- 影の既定は、実機の描き込み（白 (246,243,237)、影 (216,201,187)、境界は白目の中央で高さ約 0.5・左右の端で約 0.3）に合わせた。影の色は白と影の比で、強さ 1 で元の濃さになる。ON にした直後の見た目が元に近くなるようにするため（ユーザーが ON にしてから調整する前提）。まぶたへの追従は実機で 0.2 に決めた（ジト目・微笑みで閉じ具合が 0.3〜1 になり、0.5 だと見えている白目が全部影になる。0.2 なら描き込みと同じく下に白が残る）
- 瞳の光沢の ON/OFF（`enabled`）とは独立させる。どちらもメイドの `enabled` が親スイッチ
- `FillMissing` で色の null を補い、`ClampValues` で範囲へ丸める（既存の作法）
- 瞳のプリセットにも含める（`EyePreset.eye` 経由で自動的に入る）。プリセットの適用で `scleraShadowEnabled` も適用する（見た目の設定のため。`eye.enabled` を適用しない既存の扱いとは分ける）

### UI

- 「目」タブに「白目の影」のセクションを足す。並びは上から「白目の影を描く」トグル、強さ、色、高さ、ぼかし、反り、まぶたへの追従、白目の色の指定トグル、白目の色
- 既存の「上まぶたの影」のセクションと同じ部品・ツールチップの作法に従う
- 白目のマテリアルが見つからない顔では、セクションの先頭に「この顔では白目が見つかりません」と出す

## テスト

- `ScleraBounds`: 瞳の外接箱の内側の三角形だけが選ばれる、1 頂点でも外なら選ばれない、該当なしで範囲なし、UV の外接矩形が正しい
- `EyeSettings`: 新しい項目の既定・`FillMissing`・範囲への丸め、XML の往復
- `EyePreset`: 新しい項目が保存・適用される
- 実機: 影を ON にして描き込みの影が消え、スライダーどおりに影が出る。まばたきで影が下へずれる。OFF で元の見た目に戻る。口内・歯・舌の見た目が変わらない。COM3D2 (2.0) のバンドルがコンパイルできる

## 対象外

- ライトの向きに反応する影（まぶた・まつ毛が落とす影）
- 名前に `Mouth` を含まない MOD の顔での白目の検出（必要になったら幾何だけの判定を検討する）
- `_MainTex_ST`（タイリング・オフセット）や UV アニメーションが恒等でない口のマテリアル。範囲はメッシュの生の UV から求めるため、白目の範囲がずれる
- 白目の下側の明るさやハイライトなど、影以外の表現
