# COM3D25.MToonMaid.Plugin 設計 v2.4（顔を平らに）

日付: 2026-10-09
前提: `2026-10-09-mtoon-maid-sphere-normal-design.md`（v2.3）の設計を引き継ぐ。ここに書いたことだけを変える。

## 背景

v2.3 の「顔の陰影を球に」で口元・鼻の凹凸の影は消えたが、頭を球として陰影するため、横からの光で顔の半分が影になる。アニメ調の「顔はほぼ均一に明るい」見た目（元の Toony の顔）にはならない。

2026-10-09 に実機で試作した（球の中心を頭のボーンのローカル -Y へずらした）:

- 頭のボーン（`body0.trsHead`）のローカル +Y が顔の正面、-X が上
- 中心を 0.1 後ろ: 横からの光で頬に柔らかいグラデーションが残る
- 中心を 0.3 後ろ: 横からの光でも顔全体が明るい
- 中心を 0.3 後ろで光が後ろ寄り（顔の正面と光の向きの内積 -0.64）: 顔全体がまとめて影側になる

## 球の中心を頭の後ろへずらす

- 陰影用の球の中心を、v2.3 で控えた頭の中心から頭の後ろ（頭のボーンのローカル -Y）へずらす。中心が後ろへ行くほど顔の各点の球面の法線が正面へそろい、顔全体が同じ明るさに近づく
- ずらす量は「顔を平らに」（0〜1）× 0.5（頭のボーンのローカルの長さ。メイドの拡大縮小に追従する）
- 「顔の陰影を球に」（強さ）が 0 なら、「顔を平らに」の値によらず今までどおり（メッシュの法線）
- 他の振る舞い（`N·L` だけに使う、顔のグループだけ、中心が決まるまでは効かない）は v2.3 のまま

## 受け渡し

- 頭の後ろ向きのベクトル（頭のボーンのローカル (0, -0.5, 0) を世界座標のベクトルにしたもの）を、`_HeadCenter` と同じく毎フレーム描画の直前（`Application.onBeforeRender`）に顔の変換済みマテリアルへ `_HeadBack`（xyz、w = 0）として入れる。頭のボーンが無いときは (0,0,0,0)
- 「顔を平らに」はグループの設定値として `ApplyGroup` が `_FaceFlatten` に入れる（顔のグループだけ。他は 0。0〜1 に抑える）
- シェーダーは陰影の球の中心を `_HeadCenter.xyz + _HeadBack.xyz * _FaceFlatten` とする

## 設定

- 継承の単位に「顔を平らに」を足し、16 項目にする。キーは `faceFlatten`、グループの値は `faceFlatten`（float、0〜1、既定 0.5）
- 既定 0.5 なのは、「顔の陰影を球に」を上げるだけでアニメ調の平らな顔になるようにするため（中心 0.25 後ろ。試作の 0.1 と 0.3 の間）。強さの既定が 0 なので既存の見た目は変わらない
- ウィンドウでは「顔の陰影を球に」の下にスライダー「顔を平らに」を置く。「顔の陰影を球に」と同じく全タブで同じ位置に出し、肌・髪・衣装のタブでは個別のトグルを含めて行ごと無効表示にする
- 設定ファイルの版は 3 のまま。要素の無いファイルは既定 0.5 で読む

## 範囲外

- 顔の正面の軸の手動の調整（頭のボーンのローカル +Y 固定）
- 「顔を平らに」が 1 を超える（中心が 0.5 より後ろ）設定

## 実機検証の結果

2026-10-09、COM3D2.5 の SceneDaily（セーブ スロット 42）、メイド 0 で確かめた。

- プロパティ: 顔の `_FaceFlatten` は既定 0.5、`_HeadBack` の長さは 0.562（0.5 × 頭のボーンの拡大率 ≈ 1.12）で、顔の正面との内積は -1.00。体の `_FaceFlatten` は 0、髪の `_HeadBack` は (0,0,0,0)
- 受け渡しのタイミング: 当初の `LateUpdate` では、描画される頭から `_HeadCenter` が 1.5cm、`_HeadBack` の向きが約 18° ずれていた（顔の正面との内積 -0.95。視線の追従などが `LateUpdate` の後で頭を回すため）。`Application.onBeforeRender` へ移すと差は 0 になった
- 見え方（強さ 1、メインライトを横向き euler (20,120,0)）: 「顔を平らに」0 では顔の半分が影（v2.3 と同じ）、0.5 では顔全体が明るく左の輪郭にわずかなグラデーション、1 では顔全体が均一に明るい。0 → 1 で影が減るので、頭のボーンのローカル +Y が顔の正面で正しい。顔に NaN の点は出ない。既定 0.5 は狙いどおりなので変えない
- 強さ 0: 「顔を平らに」0 と 1 のスクリーンショットが同じ（影の境界が鼻・口元の凹凸に沿う）。`_SphereNormal` 0、`_FaceFlatten` 1
- 追従: 顔の正面が (0.111, 0.042, 0.993) → (0.233, 0.220, 0.947) と動いても、`_HeadBack` との内積は -1.000 のまま
- ウィンドウ: 共通タブの「顔の陰影を球に」の下に「顔を平らに」(0.50)。肌・髪タブでは個別のトグルを含めて行ごと無効表示、顔タブでは有効
- `LogOutput.log` に MToonMaid 由来の例外は無い
