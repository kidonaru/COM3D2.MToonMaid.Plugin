# COM3D25.MToonMaid.Plugin 設計 v2.5（凹凸の影を消す）

日付: 2026-10-09
前提: `2026-10-09-mtoon-maid-face-flatten-design.md`（v2.4）の設計を引き継ぐ。ここに書いたことだけを変える。

## 背景

v2.3 / v2.4 の「顔の陰影を球に」「顔を平らに」は、陰影の法線そのものを球へ寄せる。口元・鼻の影は消えるが、顔の立体的な陰影（横からの光で片側が影）も一緒に弱まる。立体感を残したまま、鼻・口元の細かい凹凸の影だけを消したい。

MToon には、境界の位置を場所ごとにずらす `_ShadingShiftTex`（R チャンネル × `_ShadingShiftTexScale` を `_ShadingShiftFactor` に足す）がある。VRM のモデルでは口元・鼻を白く塗ったものを手で用意するが、COM3D2 の顔には無い。これを顔のメッシュから自動で作る。

2026-10-09 に実機で試作した（メイド 0、顔の肌のサブメッシュ、頂点 1446）:

- 凹凸の強さの計算 43ms。256×256 への描き込みとぼかしも同程度
- マスクは鼻・小鼻・口の線・目のまわり・耳に強く出る
- 頭に対して横からの光で、強さ 1 にすると鼻の横と口元の影の塊が消え、頬の大きな明暗は残る
- 後ろからの光（顔全体が影）で、強さ 1 では鼻の線と口角が細く明るく浮く（光の向きによらず境界をずらすため）

## マスクの作り方

1. 顔のメッシュの、マテリアルに対応するサブメッシュの三角形が使う頂点ごとに、凹凸の強さを出す: `1 - dot(法線, 周りの法線の重み付き平均)` を 0.5 で割って 0〜1 に抑える
   - 周りは半径 0.025（メッシュのローカル。鼻・口元の凹凸より大きく、頬の丸みより小さい）。重みは `1 - 距離² / 半径²`
   - 近傍は半径の格子で探す（MOD の顔は頂点が数千あり、総当たりでは重い）
2. 頂点の値を UV（チャンネル 0）の 256×256 へ三角形ごとに描き込む（重心座標で補間）
3. 覆っていない画素を 4 回、周りの覆った画素の平均で広げる（UV の継ぎ目でバイリニアが外側の 0 を拾わないように）
4. 半径 2 の平均で 2 回ぼかす
5. R に値を入れた RGBA32・リニア・Clamp・ミップマップなしのテクスチャにする

- 表情は頂点と法線を毎回メッシュへ書き込むため、TMorph が持つ変形前の頂点・法線（`m_vOriVert` / `m_vOriNorm`）があればそれを使う。無いか数が合わなければメッシュの今の値を使う
- マスクは表情に追従しない（変形前の形で決まる。表情での頂点のずれは試作で最大 3.3mm）

## 適用

- 対象は顔のグループの変換済みマテリアル（v2.3 の `UsesSphereNormal` と同じ）。肌・口など、マテリアルごとに自分のサブメッシュから作る
- 強さ（「凹凸の影を消す」）が 0 より大きくなった顔のマテリアルにだけ作る（数十 ms かかるため、使わない間は作らない）。一度作ったマスクは、そのマテリアルを戻すか破棄するまで使い回す
- 強さが 0 より大きければ `_ShadingShiftTex` にマスク、`_ShadingShiftTexScale` に強さ（0〜1 に抑える）を入れる。0 なら `_ShadingShiftTex` を外す（パラメーターマップのキーワードが切れ、サンプリングしない）
- 作れなかった（メッシュが読めない、UV や法線の数が合わない、サブメッシュが無い）マテリアルは、警告を 1 回出して以後は作らない
- 元へ戻すときは `_ShadingShiftTex` を外し、マスクを破棄する。マテリアルが破棄されたときもマスクを破棄する

## 設定

- 継承の単位に「凹凸の影を消す」を足し、17 項目にする。キーは `faceBumpLift`、グループの値は `faceBumpLift`（float、0〜1、既定 0）
- ウィンドウでは「顔を平らに」の下にスライダー「凹凸の影を消す」を置く。「顔の陰影を球に」と同じく全タブで同じ位置に出し、肌・髪・衣装のタブでは個別のトグルを含めて行ごと無効表示にする
- 設定ファイルの版は 3 のまま。要素の無いファイルは既定 0 で読む

## 範囲外

- 表情への追従（表情ごとにマスクを作り直す）
- 光の向きに応じた効き方の調整（後ろからの光で凹凸が浮く件は、強さを下げて対処する）
- 顔以外（体・衣装）のマスク
- 半径やぼかしの手動の調整
- メッシュの大きさへの追従（半径 0.025 はメッシュのローカルの絶対値。標準の顔で決めた。単位や大きさの違う MOD の顔ではマスクが全面 0 や全面 1 に寄りうる）
- `_MainTex_ST`（タイリング・オフセット）が既定でないマテリアル（シェーダーは変換後の UV でサンプルするため、メッシュの UV とずれる）。UV が重なる（左右で共有する）部分は後から描いた三角形の値になる

## 実装メモ

- 計算（`BumpMaskBaker`）は Unity の型を使わず、頂点・法線は xyz、UV は uv を頂点順に詰めた `float[]` で受ける。テストの net48 では Unity 2022 の `UnityEngine.CoreModule`（netstandard 2.1 を参照）を読めないため。`FaceBumpMask` が `Vector3[]` / `Vector2[]` から詰め替える

## 実機検証の結果

2026-10-09、セーブ 42、メイド 0（Nekomimi）の頭（肌 `face_tokinagare_Skin`・口 `Face006_Mouth`）で確かめた。

- 既定（強さ 0）ではマスクを作らない。肌・口とも `_ShadingShiftTex` は null、`_MTOON_PARAMETERMAP` は OFF
- 強さ 1 にすると肌・口に `MToonMaid_BumpMask` が入り、`_ShadingShiftTexScale` は 1、キーワードは ON。2 枚の作成と適用に 91ms。作れないという警告は出ない
- 強さを 0 に戻すとテクスチャを外し、キーワードも切れる。マスクは残り、再び上げると作り直さずに使い回す
- 「顔の陰影を球に」0 で頭に対して横（前寄り）からの光: 強さ 1 で鼻の横から口元にかけての影の塊が消え、反対側の頬の大きな影は残る。顔に点や UV の継ぎ目の線は出ない
- 後ろからの光（顔全体が影）: 強さ 1 では鼻先が明るく浮き、口の線も少し浮く。0.5 では鼻先に小さく残る程度
- ユーザーの設定（「顔の陰影を球に」0.47・「顔を平らに」0.25）との併用: 球で口元の影がすでに消えているため、強さ 0 / 0.5 / 1 の差はほとんど無い（頬の影の縁がわずかに動く程度）。明るい斑は出ない。凹凸の影を消すは、球を使わずに立体感を残したいときに効く
- メイドの MToon を OFF にすると、次のフレームでマスクは 0 枚になる。ON に戻すと強さ 1 のまま 2 枚作り直される
- ウィンドウ: 共通タブの「顔を平らに」の下に「凹凸の影を消す」が出る。肌・髪タブでは個別のトグルを含めて行が無効表示、顔タブでは有効。MToonMaid 由来の例外は無い
