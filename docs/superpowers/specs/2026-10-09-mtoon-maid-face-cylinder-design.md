# COM3D25.MToonMaid.Plugin 設計 v2.6（上下の丸みを消す）

日付: 2026-10-09
前提: `2026-10-09-mtoon-maid-bump-mask-design.md`（v2.5）の設計を引き継ぐ。ここに書いたことだけを変える。

## 背景

v2.5 の「凹凸の影を消す」を 1 にしても、上からの光で口の上下に横向きの影の境目が残る。境目は法線の上下の成分から出ていて、マスクで境界をずらしきれない。

2026-10-09 に実機で試作した（メイド 0、顔の肌と口のサブメッシュの法線を一時的に書き換え）:

- 陰影の法線を、頭の上下の軸を中心にした円柱の法線（頭の中心からの向きから上下の成分を抜いたもの）にすると、口元・鼻の影は出ず、横からの光では顔を縦に分ける 1 本の境目になる
- 前寄りの上からの光では顔全体が光側になり、口元の境目は出ない
- 元の法線と円柱を 6:4 で混ぜると、境目は少し曲がる程度で、鼻の影がわずかに残り、口元はきれい
- 中心を「顔を平らに」1 の位置（頭の後ろ）へずらした円柱では、顔全体がほぼ正面向きになり左右の明暗も出ない

## 方式

v2.3 / v2.4 の球の法線（`_SphereNormal` / `_HeadCenter` / `_FaceFlatten` / `_HeadBack`）の形を変える。

- 球の法線 `p - c`（`p` は描く点、`c` は中心）から、頭の上向き `u`（単位ベクトル）の成分を `_FaceCylinder` の割合で抜いてから正規化する: `n = normalize(d - u * dot(d, u) * _FaceCylinder)`、`d = p - c`
  - 0 で今の球、1 で円柱
  - 混ぜ方（`_SphereNormal` による元の法線との lerp）と中心のずれ（`_FaceFlatten`）は変えない
- 頭の上向きは、頭のボーンのローカルの −X（`Vector3.left`、実機で確認）をワールドへ変換したもの。`_HeadBack` と同じく毎フレーム顔の変換済みマテリアルへ入れる。中心が無いときは 0 を入れる（`_HeadCenter.w = 0` で球自体が効かない）
- `_FaceCylinder` は顔のグループ（`UsesSphereNormal`）だけに入れ、ほかは 0

## 設定

- 継承の単位に「上下の丸みを消す」を足し、18 項目にする。キーは `faceCylinder`、グループの値は `faceCylinder`（float、0〜1、既定 0）
- ウィンドウでは「顔を平らに」の下（「凹凸の影を消す」の上）にスライダー「上下の丸みを消す」を置く。「顔の陰影を球に」と同じく全タブで同じ位置に出し、肌・髪・衣装のタブでは個別のトグルを含めて行ごと無効表示にする
- 設定ファイルの版は 3 のまま。要素の無いファイルは既定 0 で読む
- 「顔の陰影を球に」が 0 なら効かない（球の法線を混ぜないため）

## 範囲外

- 上や下からの光での顔の上下の明暗（円柱に寄せるほど付かなくなる。強さで調整する）
- 円柱の軸の向きの手動の調整（頭のボーンの軸に固定）
- 「凹凸の影を消す」との自動の連携（それぞれ独立に効く）

## 実機検証の結果

2026-10-09、セーブ 42、メイド 0（Nekomimi）の頭（肌 `face_tokinagare_Skin`・口 `Face006_Mouth`）で確かめた。

- 「上下の丸みを消す」1 で、肌・口の `_FaceCylinder` は 1、`_HeadUp` は頭のボーンの −X をワールドへ変換したもの（長さ 1）と一致する。顔以外の MToon 14 枚は `_FaceCylinder` 0
- 「顔の陰影を球に」1・「顔を平らに」0・「凹凸の影を消す」0 で比べた
  - 横（前寄り）からの光: 0 は頬で丸く曲がる境目（v2.5 までの球と同じ）、0.5 は曲がりが小さくなり、1 は顔を縦に分けるまっすぐな境目になる。境目が横向きに出ないので、上向きの軸は合っている
  - 前寄りの上からの光: 0 は目の下に横向きの境目が出て顔の下半分が影になる。1 では横向きの境目が消え、顔全体が光側になる
- ユーザーの今の設定は「顔の陰影を球に」0 のため、「上下の丸みを消す」は効かない（球を混ぜる重みが 0）。使うときは「顔の陰影を球に」を上げる
- ウィンドウ: 共通タブの「顔を平らに」と「凹凸の影を消す」の間に出る。肌・髪タブでは個別のトグルを含めて行が無効表示、顔タブでは有効。MToonMaid 由来の例外は無い
