# COM3D25.MToonMaid.Plugin 設計 v2（UI 刷新・対象の細分化・髪の見た目）

日付: 2026-10-08
前提: `2026-10-08-mtoon-maid-design.md`（v1）の設計を引き継ぐ。ここに書いたことだけを変える。

## 変更点の一覧

| 項目 | v1 | v2 |
|---|---|---|
| UI | GUILayout 直書きの IMGUI ウィンドウ | MTEUtils の `GUIView` + `DockableWindowBase` + `WindowManagerBase` |
| 置き換え対象 | メイド単位の ON/OFF だけ | メイド単位（親スイッチ）× 部位グループ単位の ON/OFF × スロット単位の除外 |
| 明るさ・影色 | グループ設定の `_ShadeColor` だけ | Toony の `_ToonRamp` から光側・影側の色を自動で算出し、グループ設定を掛ける |
| 天使の輪 | 反映しない | フォークしたシェーダーで Toony と同じ式を再現する |

## MTEUtils の取り込み

- MTEUtils は既存の submodule（リポジトリ直下 `MTEUtils/`）のまま使う。ファイルのコピーはしない
- csproj は SDK 形式なので、必要なファイルを `<Compile Include="..\..\MTEUtils\X.cs" Link="MTEUtils\X.cs" />` で個別に並べる（MTEUtils 側は「他プラグインの csproj が明示列挙する」前提で作られている）
- 必要なのは GUIView・DockableWindowBase・WindowManagerBase と、その推移的な依存（約 27 ファイル）。`UnityEngine.AnimationModule` の参照を足す
- SceneEditor が無くても単体で動く（`DockingClient` 等はホストが見つからなければ何もしない）。SceneEditor があればドッキングに参加する
- カメラ・ゲーム UI・ギズモの入力の抑止は、PostEffects の `WindowManager` と同じ方式（自分が止めたときだけ戻す）に置き換える。v1 の `UpdateCameraLock` は削除する

## 置き換え対象の制御

- メイドの「MToon にする」は親スイッチとして残す。OFF なら何もしない（v1 と同じ）
- 部位グループ（肌・顔・髪・衣装）ごとに「このグループを MToon にする」を持つ。既定は ON
- グループ内でスロット（`TBodySkin.Category`。`body` / `head` / `hairF` / `wear` / `accHat` など）ごとに除外できる。除外の一覧はメイド単位で保存する
- あるスロットが対象かは「グループが ON かつ除外されていない」で決める
- 対象から外れたスロットの変換済みマテリアルは、次の走査を待たずに元へ戻す（戻し方は v1 の OFF と同じ。ゲームの shader コマンドの戻し先の補正も含む）

## 髪の見た目（調査結果）

2026-10-08 に実機で確かめた。

### 明るさのずれ

- 髪の Toony は `_ToonRamp` を明るさに掛ける。髪のランプは無限色が作る RenderTexture で、黒髪の例では光側 0.58・影側 0.40 のグレーだった。MToon はランプを使わないため、髪が約 1.7 倍明るく見える
- 他の部位のランプは光側が 1.0 で、影側に色味（衣装の青み・肌の赤みなど）が付いている
- 無限色で髪の色を変えると、同じ RenderTexture へ描き直され（インスタンスは同じ、`updateCount` も増えない）、光側の値が変わる（例: 0.58 → 1.0）
- 対処: 変換時にランプの中央の行を読み、右端（光側）と最も暗い画素（影側）の色を取る。肌のランプ（`toonskin_SKB.tex`）は左から 3 割あたりが最も赤く暗く (0.98, 0.80, 0.83)、左端は (1.00, 0.96, 0.96) と白へ戻るため、左端では影の赤みが消える。顔・髪・衣装のランプは左端が最も暗い（実機で確認）。MToon の影は 1 色なので、Toony の境目だけが赤い帯の形までは再現しない。光側はフォークに足す `_ToonRampLitColor` でアルベドに掛け、影側はグループ設定の影色に掛けて `_ShadeColor` に入れる。ランプが無いマテリアルは白（1.0）として扱う
- 無限色の変化は `maid.Parts.GetPartsColor` の値（全フィールド）の変化で検知し、ランプを読み直して値を入れ直す
- ゲームは無限色の RenderTexture を共有プール（`RenderTextureCache`）で使い回すため、同じインスタンスが別の髪・別のスロットのランプになりうる。ランプの値はテクスチャ単位でキャッシュせず、マテリアルの控えごとに持つ（変換・再変換・無限色の変更のときに読む）
- ランプ由来の色味が影に入るため、グループ設定の影色の既定は全グループ白にする（v1 の肌の既定 (1, 0.93, 0.93) は廃止。設定ファイルの版を 2 に上げ、旧既定のままの肌は白へ置き換える）

### 天使の輪

- Toony の髪のハイライトは次の式（実測による）
  - `highlight = _HiTex.rgb(uv0) × _HiTex.a(uv0) × _HiRate × pow(saturate(N·H), _HiPow)`（H はライトと視線の中間ベクトル）
  - 無限色の `_HiTex` は RGB が一様な髪色（黒髪の例で 0.576）で、輪の形はアルファにある（実装後の実機検証で判明。当初の式はアルファを掛けておらず、髪が約 1.76 倍明るかった）
  - ハイライトはアルベドへ加算され、その後にランプとライトの陰影が掛かる。影側にも掛かる
  - アンビエント（GI）には掛からない（ライトの強さを半分にするとほぼ比例して減る）
- バニラの髪は `_HiPow` = 0.001 なので角度の項はほぼ 1 で、輪の形は `_HiTex`（無限色の RenderTexture）の模様で決まる
- MToon の発光で代用すると陰影が掛からず白っぽくなるため、シェーダーに式を足す
- 対処: フォークに `_HiTex` / `_HiRate` / `_HiPow`（ゲームと同名。シェーダーを差し替えても値が引き継がれるので C# からは書かない）と、MToon 側だけの倍率 `_HiRateScale` を足す。直接光の項で、光側に `highlight × _ToonRampLitColor`、影側に `highlight × _ShadeColor` を足してから陰影を混ぜる。Toony のアウトラインは単色なので、アウトラインのパスには足さない
- グループ設定に「天使の輪の強さ」（`_HiRateScale`、既定 1）を足す。`_HiTex` を持たないマテリアルでは効かない

## 設定ファイル（版 2）

v1 の項目に加えて:

- メイド: `excludedSlots`（除外するスロット名の一覧）
- グループ: `enabled`（既定 true）、`highlightScale`（既定 1）
- 版 1 のファイルは読み込み時に版 2 へ上げる。欠けた項目は既定値、肌の影色が旧既定と一致すれば白へ置き換える

## 範囲外

- `_ToonRamp` の境界位置（光と影の切り替わる位置）から `_ShadingShiftFactor` を決めること。グループ設定のまま
- `_HiTex` の `_ST`（タイリング）。MToon の UV（`_MainTex_ST` と UV アニメーション）で引く
- 追加ライト（ForwardAdd）での天使の輪。MToon の直接光の関数を通るので出るが、Toony との一致は確かめない

## 実機検証の結果

2026-10-09 にデイリー画面（セーブ 42、メイド 0 の黒髪）で確かめた。

| 項目 | 結果 |
|---|---|
| 髪の明るさ（髪の画素の平均） | バニラ 0.215 / MToon 0.227（比 1.06）。天使の輪にアルファを掛ける前は 0.218 / 0.384（比 1.76） |
| 髪の明るさ（メインライト 0.3 倍） | バニラ 0.060 / MToon 0.063（比 1.06）。GI に `_ToonRampLitColor` を掛ける構成のままでよい |
| 天使の輪の寄与（Toony） | `_HiRate` を 0 にした差の最大 0.173 = 0.576（RGB）× 1（アルファ最大）× 0.554（`_HiRate`）× 0.576（ランプ光側）× 0.95（ライト）で、式と一致 |
| ランプの値 | 黒髪で光側 0.576・影側 0.396。無限色（色相 0・彩度 200・明度 300）で次の走査後に光側 0.996・影側 (0.980, 0.843, 0.843)、元の色へ戻すと 0.576 / 0.396 に戻る |
| 肌の影の赤み（メインライトを背後へ回し、バニラで肌に当たる画素の平均） | バニラ (0.945, 0.655, 0.611)・R/G 1.44 / 最も暗い画素を影側にした MToon (0.971, 0.693, 0.656)・R/G 1.40 / 左端を影側にした旧実装 (0.978, 0.848, 0.774)・R/G 1.15。`_ShadeColor` は (0.980, 0.800, 0.827) で、髪・衣装の値は変わらない |
| グループの OFF・スロットの除外 | 髪を OFF にすると次フレームで髪だけ `CM3D2/Toony_Lighted_Hair_Outline_Tex` に戻り、肌は MToon のまま。`accHat` を除外すると `CM3D2/Toony_Lighted_Outline_Tex` に戻り、解除で MToon に戻る |
| ウィンドウ | コンボボックス・タブ・各行・スロット一覧が描かれ、上書きしない色の行は無効表示。衣装タブへ切り替えても崩れない。ログに `ArgumentException` や MToonMaid 由来の例外は無い |
| 設定ファイル | `version="2"`・肌の影色が白・`excludedSlots` ありで保存される |
| 起動 | `GUIView` の静的初期化が `Texture2D` を作るため、ウィンドウを Awake で作るとネイティブでクラッシュした。最初の Update で作るよう変えて解消 |

確認できなかった項目:

- ウィンドウ上のマウス操作でカメラが動かないこと（devbridge ではマウスを動かせない）
- SceneEditor のウィンドウと同時に開いたときの描画とポップアップ、ドッキングへの参加
- 天使の輪の帯の見た目（このメイドはフードで頭頂が隠れていた）と、アウトラインに乗らないこと
