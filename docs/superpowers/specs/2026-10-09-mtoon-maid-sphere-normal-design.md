# COM3D25.MToonMaid.Plugin 設計 v2.3（顔の陰影を球に寄せる）

日付: 2026-10-09
前提: `2026-10-09-mtoon-maid-additional-light-design.md`（v2.2）の設計を引き継ぐ。ここに書いたことだけを変える。

## 背景

MToon は `N·L`（表面の向きと光の向き）でトゥーンの境界を引く。顔のメッシュは口元・鼻・頬で法線が細かく変わるため、光の向きによっては口元から頬の下にくっきりした影が入る。元の Toony では顔全体がほぼ均一に明るく、この影は出ない（2026-10-09 に実機で確認。メインライトの影の強さは 0.098 で、落ち影ではない）。

顔グループの「境界の位置」を上げると影は消えるが、顔の陰影そのものが弱まり、横からの強い光でも影が入らなくなる。

## 陰影の法線を頭の球面へ寄せる

- 陰影（`N·L`）に使う法線を、メッシュの法線と「頭の中心から表面へ向かう方向」（球面の法線）の間で混ぜる: `normalize(lerp(N, normalize(positionWS - 頭の中心), 強さ))`
  - 強さ 0 なら今までどおり。1 なら頭を球とみなした陰影になり、口元や鼻の凹凸で影が入らず、光の向きに合わせて顔全体がなめらかに明暗する
- 混ぜた法線を使うのはトゥーンの陰影（メインライト・追加ライトの `N·L`）だけ。環境光（SH）、リムのフレネル、天使の輪、アウトラインの押し出しはメッシュの法線のまま
  - 陰影に連動するものは間接的に球へ寄る: アウトラインの色（`_OutlineLightingMix` が 0 より大きいとき）、追加ライトのリムに掛かる影
- 効くのは顔のグループのマテリアルだけ。髪は毛先が頭から遠く（ロングヘアやツインテールは胸から腰の高さ）、頭の中心からの放射方向では上からの光で毛先が暗くなるなど不自然になるため対象にしない。肌・髪・衣装のグループには常に 0 を入れる

## 頭の中心

- 頭のスロット（`head`、親スロットで表示中のもの）の描画のバウンズの中心を、頭のボーン（`body0.trsHead`）から見た相対位置として控える。バウンズには表示中で有効なレンダラーだけを含める。控えるのは頭のスロットの GameObject か頭のボーンが変わったときだけで、控え直せるまでは前の中心を使わない（走査のたびに取り直すと、表情や頭の傾きでバウンズが揺れ、陰影の境界がちらつくため）
- バウンズの大きさが 0、または中心が頭のボーンから 0.3 以上離れているときは採用せず、次の走査で取り直す
- 毎フレーム描画の直前（`Application.onBeforeRender`）に、頭のボーンからその相対位置を世界座標へ戻し、顔のグループの変換済みマテリアルへ `_HeadCenter`（xyz = 中心、w = 1）として入れる
- 頭のスロット・頭のボーンが無い、または中心を控えられていないときは `_HeadCenter` を (0,0,0,0) にする。シェーダーは `_SphereNormal × _HeadCenter.w` を強さに使うため、中心が決まるまで（変換直後の 1 フレームを含む）は効かない
- 視線の追従などが `LateUpdate` の後で頭を回すため、`LateUpdate` で入れると描画される頭から中心が 1.5cm・向きが約 18° ずれる（v2.4 の実機検証で判明）。描画の直前に入れることで一致させる

## 設定

- 継承の単位に「顔の陰影を球に寄せる」を足し、15 項目にする。キーは `sphereNormal`、グループの値は `sphereNormal`（float、0〜1、既定 0）
- 既定 0 なので、既存の見た目は変わらない。顔の口元の影が気になるときは、顔タブで個別にして上げる
- ウィンドウでは「陰影」の「追加ライトの影側」の下にスライダー「顔の陰影を球に」を置く。全タブで同じ位置に出し、肌・髪・衣装のタブでは個別のトグルを含めて行ごと無効表示にする（効かないため。行を消すと入力欄キャッシュの番号がずれる）。共通タブでは有効（顔に効く）
- 設定ファイルの版は 3 のまま。要素の無いファイルは既定 0 で読む
- マテリアルへ入れる値は 0〜1 に抑える

## 範囲外

- 顔用の影のテクスチャ（SDF）による陰影
- 顔以外（髪・体・衣装）の球面の法線
- 頭の中心の手動の調整

## 実機検証の結果

2026-10-09、COM3D2.5 の SceneDaily（セーブ スロット 42）、メイド 0 で確かめた。

- プロパティ: 顔の MToon マテリアルに `_SphereNormal` があり、既定で 0。`_HeadCenter.w` は 1、中心と頭のボーンの距離は 0.071。体・髪のマテリアルの `_HeadCenter` は (0,0,0,0)
- 既定 0: 正面寄りのメインライト（ゲームの既定）では見た目に変化なし。メインライトを横向き（euler (20,120,0)）にすると、影の境界が鼻・口元の凹凸に沿ってギザギザに入る（今までどおり）。顔に NaN の点は出ない
- 強さ 1: 共通・顔の両方を 1 にしても `_SphereNormal` は顔 1・髪 0・体 0。横向きのライトで、影の境界が凹凸に沿わない滑らかな斜めの線になり、口元・鼻の影が消えた
- 追従: 頭のボーンの位置が (0.037, 1.198, -0.057) → (0.037, 1.201, -0.063) と動いても、中心との距離は 0.0712 で一定
- ウィンドウ: 共通タブの「追加ライトの影側」の下に「顔の陰影を球に」(0.00)。肌・髪タブでは個別のトグルを含めて行ごと無効表示、顔タブでは有効
- `LogOutput.log` に MToonMaid 由来の例外は無い
