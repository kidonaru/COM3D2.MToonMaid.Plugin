# COM3D25.MToonMaid.Plugin 設計 v2.8（前髪の影）

日付: 2026-10-09
前提: `2026-10-09-mtoon-maid-remove-sphere-design.md`（v2.7）までの設計を引き継ぐ。ここに書いたことだけを変える。

## 背景

soToonShader（COM3D2 用、スクリーン空間のポストエフェクト）との差分を調べたところ、前髪の影（前髪が額・目元へ落とす影）が MToonMaid に無い。MToon の陰影は法線と光の向きだけで決まり、前髪が顔へ影を落とさない。ゲームの影（シャドウマップ）は解像度とバイアスの都合で前髪の細い影が出ない。

soToon は前髪を頭のボーン基準で固定量ずらし、画面サイズの RT で深度を比べて顔に重ねる。MToonMaid はマテリアルを差し替える方式なので、メイドごとの小さな影マップ（前髪だけを投影した深度）を顔のシェーダーで読む形にする。投影の向きは、ライト追従と固定（頭のボーン基準）を切り替えられる。

方式を比べた結果:

- 小さな影マップ（採用）: 深度で比べるため、後ろからの光で顔の前側に影が出るといった誤りが無い。カメラに依存しないので VR・SceneCapture・複数カメラでも同じ。向きの切り替えは行列が変わるだけ
- スクリーン空間（soToon 方式）: カメラごとに RT が要り、ずらす量が画面上の大きさに引きずられる。ライト追従にすると結局影マップと同じ計算が要る
- 深度なしのシルエット投影: 光が後ろ寄りだと顔の手前側に誤った影が出る。手間は影マップと変わらない

## 設定

継承の単位に 6 項目を足し、21 項目にする（ずらし・解像度・ぼかしは実装中にユーザーの要望で追加した。当初の「固定の角度」と、その後に足した「固定の左右」の角度は、座標のずらしに置き換えて外した）。効くのは顔のグループだけで、肌・髪・衣装のタブでは「凹凸の影を消す」と同じく個別のトグルを含めて行ごと無効表示にする。

| 表示名 | キー / フィールド | 型・範囲・既定 | 意味 |
|---|---|---|---|
| 前髪の影 | `hairShadow` | float、0〜1、既定 0 | 影の濃さ（顔の陰影を影側へ倒す量）。0 なら影マップを作らず描かない |
| 影の向き | `hairShadowMode` | enum（固定 / ライト追従）、既定は固定 | 前髪をどちらの向きから投影するか |
| ずらし 左右 | `hairShadowOffsetX` | float、-0.02〜0.02 m、既定 0.002 | 影を頭の左右の軸に沿ってずらす量。プラスはメイドから見て右（正面から見ると画面の左）。固定・ライト追従の両方で効く。メイドの大きさによらず m（頭のルートボーンのスケールは通常の大きさで 1 とは限らず、掛けると逆にずれる） |
| ずらし 上下 | `hairShadowOffsetY` | float、-0.02〜0.02 m、既定 0 | 影を頭の上下の軸に沿ってずらす量。プラスは頭の上。既定 0 では固定の影は前髪の片側の細い帯になる（既定はユーザーの指定で左右だけずらす） |
| 解像度 | `hairShadowResolution` | int、256 / 512 / 1024 / 2048、既定 512 | 影マップの一辺の画素数。一覧に無い値は使うときに最も近い値へ丸める |
| ぼかし | `hairShadowSoftness` | float、0〜3、既定 1 | 影の縁をぼかす幅（影マップの画素数）。0 は双線形 PCF だけ |

- ウィンドウでは「凹凸の影を消す」の下に 6 行を置く（解像度は 4 つのボタン）。ずらしの 2 行は小数 4 桁で表示する
- 設定ファイルの版は 3 のまま。要素の無いファイルは既定（前髪の影 0）で読む
- 深度のバイアスはコード内の固定値にする（ぼかしの幅に応じて増やす）。実機で必要ならスライダーにする

## 対象

- 影を落とす側: そのメイドの `hairF` スロット（CRC の全サブスロット `goSlot[i, subNo]`）の全レンダラーの全サブメッシュ。前髪スロットを MToon にしているか（グループの ON・スロットの除外）に関係なく使う
- 影を受ける側: そのメイドの、MToon にした顔のグループ（head スロット）のマテリアル
- メイドごとに自分の前髪だけを自分の顔へ落とす。他のメイドの前髪は影を落とさない

## 主光源の選び方（ライト追従）

MToon は ForwardBase で `_WorldSpaceLightPos0` を読むだけで、どの平行光を使うかは Unity のビルトインのフォワード描画が決める。C# 側で同じ規則を再現する:

- 候補: 有効（`isActiveAndEnabled`）な平行光のうち、`cullingMask` が顔のレンダラーのレイヤーを含み、`renderMode` が `ForceVertex`（Not Important）でないもの
- 選び方: 候補に `RenderSettings.sun` があればそれ、無ければ intensity × 色の輝度（グレースケール）が最大のもの（SceneEditor は sun を設定する。2026-10-09 の実機では sun が「追加ライト 1」だった）
- 候補が無ければ、ライト追従では影を描かない

この規則（明るさの比べ方、Important の扱い）は記憶に基づくもので、実機でライトを複数置いて顔の陰影の向きと一致するかを確かめる。ずれたら規則を直す。

## 影マップの描画

### 構成

- `Rendering/HairShadowRenderer`: メイド 1 人分の影マップ（RT・CommandBuffer・描画用マテリアル）を持ち、描いて顔のマテリアルへ渡す。`MaidMToonController` が持つ
- `Rendering/HairShadowProjection`: 投影の向き・中心・大きさから「ワールド → 影マップの UV と深度」の行列を作る。Unity の型を使わない純粋な計算にしてテストする（テストの net48 では Unity 2022 の `UnityEngine.CoreModule` を読めないため。`BumpMaskBaker` と同じ）
- `Rendering/MainDirectionalLightSelector`: 主光源を選ぶ。比べる部分は Unity の型を使わない純粋な関数にしてテストする
- `HairShadowCaster.shader`（`Hidden/COM3D25/MToonHairShadowCaster`）: 前髪の深度を書く。mtoon_bundle に足し、`MToonShaderProvider` で MToon と一緒に読む

### フレームごとの流れ

1. `Camera.onPreCull` で描く（揺れもの（前髪の物理）が LateUpdate で動いた後になるため）。`Time.frameCount` を見て、カメラが複数あってもメイドごとに 1 フレーム 1 回だけ描く
2. 次のどれかなら描かず、顔のマテリアルの `_HairShadowStrength` を 0 にする: 前髪の影が 0 / 顔に MToon のマテリアルが無い / `hairF` スロットが無い / 頭のボーンが無い / ライト追従で主光源が無い
3. 投影の向き: 固定なら頭のボーン（`Bip01 Head`）の正面から当てる。ライト追従なら主光源の向き。ずらしは前髪を描く行列には入れず、顔へ渡す `_HairShadowMatrix` の UV だけを「頭の右 × 左右 ＋ 頭の上 × 上下」だけ動かす（深度まで動かすと、光の向きに沿ったずらしで前髪より奥の顔が手前扱いになり影が抜ける）。COM3D2 の `Bip01 Head` は顔の正面が `head.up`、頭のてっぺんが `-head.right`（2026-10-09 に実機で両目の位置と `Eye_*_nub` の向きから確かめた）
4. 投影の中心は head スロットのローカルのバウンズの中心（頭のボーンの原点は首寄りにあり、余白が片側で削れるため使わない）。大きさは head スロットのレンダラーのローカルのバウンズ（`localBounds` × スケール。ワールドの AABB は頭の回転で変わり影マップの解像度が脈動するため使わない）の半径に余白を足したもの（体型スライダーで頭が大きくなっても収まるように）。正射影の幅・高さ・奥行きはこの半径から決める
5. `CommandBuffer` に `hairF` スロットの全レンダラーの全サブメッシュを `DrawRenderer` で並べ、`Graphics.ExecuteCommandBuffer` で解像度の設定の大きさの RT（RFloat、深度 16bit。解像度を変えたら作り直す）へ描く。色には投影空間の深度を書き、何も無い所は「最も遠い」（1）でクリアする
6. 毛先の切り抜き: 元のマテリアルの `_MainTex`（と `_MainTex_ST`）を使う。Cutout 系のシェーダー（`ToonMaterialClassifier.IsCutout`）だけ `_Cutoff` でクリップし、それ以外は不透明として描く。描画用のマテリアルは自分の持つ 1 枚で、テクスチャ・切り抜きの閾値・行列は CommandBuffer のグローバル値（`_MToonHairShadowCaster*` の専用名。`DrawRenderer` は MaterialPropertyBlock を取らないため）で描くたびに渡す。元のマテリアルは書き換えない
7. 顔の MToon マテリアルへ `_HairShadowTex`・`_HairShadowMatrix`・`_HairShadowStrength` を入れる。顔のマテリアルはメイドごとに別の実体なので、複数メイドでも混ざらない

### 深度の扱い

前髪のシェーダーは、クリップ空間の z ではなく、プラグインが渡す同じ `_HairShadowMatrix` で計算した深度（0〜1）を書く。描画位置にはこの行列から作った OpenGL 流のクリップ行列をそのまま `CommandBuffer.SetViewProjectionMatrices` へ渡す（CommandBuffer がプラットフォーム向けの RT の上下・逆 Z を自分で直す。`GL.GetGPUProjectionMatrix` を通すと二重に直り、影マップが上下反転することを実機で確かめた）。書く値と顔で比べる値が同じ行列から出るため、プラットフォームの逆 Z の差を受けない。

### 後片付け

- 前髪の影を 0 にしたとき・メイドの MToon を OFF にしたとき・顔のグループを外したとき・メイドが破棄されたとき・プラグインの終了時に、RT と CommandBuffer を解放する
- MToon のまま影だけを止めるときは、顔のマテリアルの `_HairShadowStrength` を 0 にし `_HairShadowTex` を外す。Toony へ戻すときはシェーダーごと戻るので要らない

### 負荷の見込み

メイド 1 人につき、512² の RT 1 枚と前髪のサブメッシュ数（数個）の描画が増える。GPU からの読み戻しは無い。

## シェーダー（MToon）

- `_HairShadowTex`（既定 white）、`_HairShadowMatrix`、`_HairShadowStrength`（既定 0）を足す
- ForwardBase の `GetMToonLighting_Shade` で、陰影の結果に `1 - _HairShadowStrength × 影の割合` を掛ける（平行光のセルフシャドウと同じ位置づけで、影色の側へ倒れる）。ForwardAdd（追加ライト）とアウトラインのパスでは掛けない。`_HairShadowStrength` が 0 ならテクスチャを読まない
- 影の割合: ワールド位置を `_HairShadowMatrix` で UV と深度に変換し、周りの 2×2 テクセルで `深度 > 前髪の深度 + バイアス` を判定して、点のテクセル内の位置で双線形に混ぜる（PCF。テクセルの格子に沿った段が出ない）。ぼかしが 0 より大きければ、ぼかしの幅を軸ごとに `ceil(ぼかし) + 1` 点（最大 4 点、間隔 1 テクセル以下）に分けた格子の PCF を平均する（読み出しは最大 64 回。間隔が 1 テクセルを超えると点の間に平らな帯ができて縁が二重に見える）。バイアスは `0.004 + ぼかし × テクセルの大きさ` に増やす（固定の倍率では解像度が高いと前髪が顔に近い所の影が抜ける）。UV が 0〜1 の外、または深度が 1 を超える（投影の立方体より奥）なら影なし
- ワールド位置は Varyings の `positionWS`（`vrmc_materials_mtoon_attribute.hlsl`）を使う。`MToonInput` へ通す

## エラー処理

- バンドルに前髪のシェーダーが無い・今のグラフィックス API で使えない: エラーを 1 回出し、前髪の影だけを無効にする。MToon への変換は動く。ウィンドウの 3 行は無効表示にし、理由を出す
- `onPreCull` の描画が例外になった: 警告を 1 回出し、そのメイドの前髪の影を止めて `_HairShadowStrength` を 0 にする。300 フレームあけて、または顔の設定を変えたらもう一度試す（着替え中の破棄済みレンダラーなど一過性の失敗で止めきらない）
- メイドが busy（着替えなど）の間は描かず、顔の強さを 0 にする
- 頭のボーン・head スロット・`hairF` スロットが見つからないフレームは、警告を出さずに描かない

## 範囲外

- 前髪以外のスロット（横髪・後ろ髪・アホ毛・帽子）からの影
- 顔以外（首・体）で影を受けること
- 目（半透明で MToon にしない）に影を落とすこと
- 追加ライト（ポイント・スポット）からの前髪の影
- バイアスのスライダー
- 影の色を陰影の影色と別にすること

## 実機検証の結果

2026-10-09、セーブ 42（日常画面）、メイド 0（Nekomimi、前髪 `hair_f004kaikai_z10.menu`、顔の境界の位置 0.75）で確かめた。この節と次の節は、固定の向きを角度で決めていたときの記録。

- 起動ログに前髪の影のシェーダーのエラーは無く、ウィンドウの顔タブに「前髪の影」「前髪の影をライトの向きに」「前髪の影の角度」が出る
- 最初の実装（`GL.GetGPUProjectionMatrix(…, true)` を通した行列）では影マップが上下反転し（毛先が上、頭頂が下）、顔の下半分が影になった。行列をそのまま `SetViewProjectionMatrices` へ渡すと毛先が下を向く正しい影マップになった
- 固定・強さ 1: 角度 30 で額から目の上に前髪の形の影が出る。角度 0 では前髪の縁だけ、80 では顔のほぼ全体が影になる（真上からの光は前髪全体に遮られる）。顔のマテリアル（`face_tokinagare_Skin`・`Face006_Mouth`）の `_HairShadowStrength` は 1、`_HairShadowTex` は `MToonMaid_HairShadow`
- 強さを 0 に戻すと `MToonMaid_HairShadow` の RenderTexture は残らず、顔の `_HairShadowStrength` は 0、`_HairShadowTex` は null。メイドの「MToon にする」を OFF にしても RenderTexture は残らず、ON に戻すと作り直される
- ライト追従: sun（`MainDirectionalLight`）を左右へ回すと、前髪の影が光と反対側へずれる
- 主光源の選び方: sun を赤（強さ 0.5、輝度 0.15）、足した平行光を青（強さ 0.6、輝度 0.23）にし、顔の影色を黒・固定 80° で前髪の影を顔全体にかけると、影の部分から赤が消えて青が残った。Unity は明るい方ではなく sun を ForwardBase に選んでおり、sun を優先する規則と一致する
- 前髪のレンダラーを非表示にすると影が消え、例外は出ない（`DelProp(MPN.hairf)` では前髪が外れなかったため、スロットが無い場合の経路は実機では通していない）
- 負荷: `OnCameraPreCull` はカメラ 4〜10 回の呼び出し込みで平均 0.054ms／フレーム（最大 0.31ms）。影を描くのはフレームに 1 回
- 未確認: 前髪の揺れへの追従の遅れ（日常画面の待機モーションでは目立つずれは無かったが、大きく揺れるモーションでは見ていない）、メイド 2 人での影の分離（メイドごとに別の RT と顔のマテリアルへ入れる構造で確認）

### 左右の角度・解像度とレビュー修正の検証（2026-10-09、同じセーブ・メイド）

- 左右 +40（メイドの右側から当てる）で影がメイドの左（画面の右）へ、-40 で反対へ寄る
- 解像度 256・2048 で `MToonMaid_HairShadow` がその大きさで作り直され、古い RenderTexture は残らない。顔タブに「前髪の影の左右」と解像度の 4 つのボタンが出て、肌タブでは無効表示になる
- 顔グループを OFF にすると、Toony に戻った顔のマテリアルの `_HairShadowStrength` が 0 になり、影マップは次のフレームで解放される

### 縁のジャギ（2026-10-09）

- 最初の実装（4 点を点サンプルして平均）は、影マップのテクセルの格子に沿った段が目立った
- 双線形 PCF だけ（ぼかし 0）でも段は細かくなるが、寄ると残る。ぼかし 1 で縁がなめらかになり、3 ではかなり柔らかい影になる（解像度 512、カメラを顔へ寄せて比較）
- レビューの指摘で、ぼかしの読む点の間隔を 1 テクセル以下にし（4 か所固定では間隔が 1 テクセルを超え、点の間に平らな帯ができて縁が二重に見える）、バイアスの増分をテクセルの大きさに比例させた。ぼかし 3 × 解像度 512 で縁は二重にならずなめらか、解像度 2048 でも前髪のすぐ下まで影が届く（抜けない）

### 角度から座標のずらしへ（2026-10-09、同じセーブ・メイド）

- ユーザーの要望で、固定の向きの角度（上下・左右）を外し、影の位置を頭の軸に沿った座標でずらす方式にした（soToon と同じ考え方）。既定は画面から見て少し左（`hairShadowOffsetX` 0.01）
- 角度・左右の要素と `overrides` のキーを持つ設定ファイルは警告なしで読め、ずらしは既定値になった
- 上下 -0.03 で影が前髪の下へ伸び、左右 -0.03（メイドの左）で影が画面の右へずれる
- その後ユーザーの指定で、ずらしの範囲を ±0.02 m、左右の既定を 0.002 m にした
